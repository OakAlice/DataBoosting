## Data augmentation for rare class detection in accelerometer-based animal behaviour classification

Machine learning enables automated classification of behaviour from animal-borne accelerometer datasets. These methods are, however, dependent on large training datasets representing each of the classes of interest. In wildlife research rare, cryptic, or logistically challenging species/behaviours tend to yield limited observations, restricting the use of these data-intensive classification approaches and often leaving small datasets and minority classes within the larger datasets, unusable. Here we attempt to overcome this limitation by evaluating a suite of data augmentation and synthetic sample generation strategies for increasing minority-class representation in accelerometer data.
